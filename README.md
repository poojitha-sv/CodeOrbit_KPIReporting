# CodeOrbit KPI Reporting Task

This is my Task 5 submission for the CodeOrbit Tech Data Analyst internship.

## Business Scenario
A small retail store selling Electronics, Furniture, and Stationery, using the same sample sales dataset as my other tasks.

## The 5 KPIs
1. Total Revenue - $1,845.24
2. Average Order Value - $76.89
3. Repeat Customer Rate - 50.0%
4. Top Category Revenue Share (Furniture) - 47.6%
5. Digital Payment Adoption Rate - 75.0%

## Repo Link
 https://github.com/poojitha-sv/CodeOrbit_KPIReporting.git



## Files here
- cleaned_business_data.csv - the sample dataset used
- calculate_kpis.py - script that calculates all 5 KPIs
- KPI_Report.xlsx - visual KPI report (KPI cards, explanation table, and 2 charts)
- KPI_Explanation_Report.md - written explanation of why each KPI matters
- kpi_summary.csv, kpi_category_breakdown.csv, kpi_payment_breakdown.csv, kpi_customertype_breakdown.csv - supporting data

## Tools used
- Python 3, pandas (for calculating the KPIs)
- Excel (for the visual report, built with openpyxl - KPI cards, table, and charts)

## How to run it
1. Install pandas: `pip install pandas`
2. Run: `python3 calculate_kpis.py`
